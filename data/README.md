# CMS Open Data

The data used in this project comes from the CMS Open Data Portal.

## Dataset

Run2012BC DoubleMuParked Muons

The dataset is derived from CMS 2012 collision data and is provided for educational/outreach analysis of the dimuon spectrum.

## Source

CERN Open Data Portal:

https://opendata.cern.ch/record/cms-12342

## ROOT file

Run2012BC_DoubleMuParked_Muons.root

The ROOT file is intentionally not included in this Git repository.

It can be accessed through the CMS Open Data infrastructure using the XRootD protocol.

## Reproducibility

The analysis notebooks contain the information required to access and analyze the dataset.

## Important note

The CMS Open Data used here is an educational/derived dataset and should not be presented as a full CMS physics analysis.
